# Тренажёры курса «Интеллектуальные информационные технологии»

Статический сайт: открывается в браузере, в том числе с телефона, ничего не нужно
устанавливать. Результаты зачётных проходов сами приходят в Google Таблицу
преподавателя и сразу видны в кабинете преподавателя — по группам и комнатам.

**Адрес стенда:** https://puffluv.github.io/iit-trainers/
**Кабинет преподавателя:** https://puffluv.github.io/iit-trainers/teacher.html

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | Главная: вход по коду комнаты, список тренажёров |
| `trainer.html?t=A` … `?t=H` | Тренажёры по лекциям 1–8 |
| `trainer.html?t=Z` | Итоговый зачёт: 24 задания, по 3 случайных из каждой лекции |
| `klaviaturnyi_pocherk.html` | Практика 2: измерение клавиатурного почерка, эталоны, аутентификация и идентификация |
| `teacher.html` | Кабинет преподавателя: комнаты, QR-код, живые результаты, журнал, выгрузка CSV |
| `consent.html` | Согласие на обработку персональных данных |
| `config.js` | Настройки: адрес таблицы (`resultsUrl`) и сведения об операторе данных |
| `apps-script/Code.gs` | Сервер в Google Apps Script: выдаёт зачётные задания без ответов, считает баллы, пишет в таблицу |
| `private/Bank.gs` | **Приватный** банк зачётных заданий с ответами. Только на этом компьютере и в Apps Script, в Git не попадает (`.gitignore`) |
| `iit-data.js` | Задания самопроверки с разбором и шпаргалки (публичные) |
| `iit.js`, `iit.css`, `qr.js` | Движок, оформление, генератор QR-кода |

## Задания

Самопроверка — 9–10 заданий по каждой лекции, с разбором (публичные).
Зачётный пул — по 17–18 «семейств» заданий на лекцию, у каждого семейства два и
больше вариантов формулировки, расчётные задания генерируются с уникальными
числами (нейрон, дельта-правило, PNN, GRNN, Кохонен, рулетка, кроссовер, код Грея,
клавиатурный почерк). Всего ~260 зачётных заданий плюс генераторы.

Студент получает 10 случайных семейств лекции (итоговый зачёт — по 3 из каждой
лекции) и в каждом случайный вариант; варианты ответа перемешаны у каждого свои.
У двух соседей в среднем совпадает 2–3 задания из 10, в итоговом — около 2 из 24.
Типы: выбор ответа, расчёт (нейрон, дельта-правило, PNN, GRNN, Кохонен,
рулетка, код Грея, интервалы клавиатурного почерка) и «расставьте по порядку»
(этапы ЭС, схема ГА, стадии OCR, история нейросетей и т. д.). После каждого
ответа в самопроверке — разбор со ссылкой на раздел лекции.

В зачётном проходе подсказок и правильных ответов нет ни во время, ни после:
студент видит баллы и список заданий с ошибками с разделами для повторения.
В итоговом зачёте у каждого свой случайный набор и разбивка результата по лекциям.

Самопроверка правится в `iit-data.js`, зачётные задания — в `private/Bank.gs`
(после правки вставьте файл в Apps Script и создайте новую версию развёртывания).
В заданиях с выбором **правильный вариант пишется первым** — при выдаче варианты
перемешиваются. Номера зачётных заданий (`4.07`) уходят в таблицу, их не стоит перенумеровывать.

## Как это устроено

1. Преподаватель входит в кабинет (пароль), выбирает тренажёр и длительность и
   создаёт комнату — код из 5 знаков и QR-код на весь экран. Комната регистрируется
   на сервере; время идёт с момента создания, кнопка «+5 минут» продлевает его
   для тех, кто ещё не начал. Придуманные коды комнат сервер не принимает.
2. Студент сканирует QR (или вводит код на главной, можно русскими буквами),
   указывает фамилию, имя, группу и даёт согласие.
3. У студента виден таймер до конца времени комнаты; когда время выходит, ответы
   отправляются сами. Задания приходят с сервера без ответов; в конце ответы уходят на сервер, он
   считает баллы и пишет строку в таблицу. Если интернет пропал — ответы
   сохраняются в браузере, их можно доотправить кнопкой (дублей не будет).
4. В кабинете результаты появляются сами (обновление каждые 15 с):
   журнал по группам (лучший % по каждому тренажёру), по комнатам,
   все попытки, самые трудные задания. Выгрузка в CSV для Excel.
5. В самой таблице: «Все результаты», отдельный лист на каждую группу,
   «Сводка по группам» (журнал с цветами) и «Комнаты».

В самопроверке ничего не отправляется.

## Подключить Google Таблицу (один раз, ~5 минут)

1. Создайте Google Таблицу, например «Результаты тренажёров ИИТ».
2. **Расширения → Apps Script**. В файл `Code.gs` вставьте содержимое
   `apps-script/Code.gs` (в кабинете есть кнопка «Скопировать код сервера»).
3. **«+» → «Скрипт»**, имя `Bank`, вставьте содержимое `private/Bank.gs`.
4. В строке `const TEACHER_KEY = '…'` впишите свой пароль — по нему кабинет читает
   результаты. Там же `MAX_ATTEMPTS` (попыток на студента в комнате, по умолчанию 3)
   и `LECTURE_ITEMS` (заданий в зачёте по лекции, по умолчанию 10).
5. Сохраните. **Развернуть → Новое развёртывание**, тип «Веб-приложение»:
   «Запуск от имени» — **Я**, «У кого есть доступ» — **Все**. Разрешите доступ
   (Google предупредит о непроверенном приложении: «Дополнительно» → «Перейти»).
6. Скопируйте URL веб-приложения (оканчивается на `/exec`) в `config.js`,
   строка `resultsUrl`, и опубликуйте изменение (см. ниже).
7. Откройте кабинет, введите пароль, нажмите «Подключиться». Пройдите любой
   тренажёр в зачётном режиме — результат появится в кабинете и в таблице.

Изменили код скрипта — «Развернуть → Управление развёртываниями → ✎ →
Версия: новая → Развернуть». Адрес `/exec` не меняется.

Оператор данных в `config.js` — СибГУТИ. Допишите `contact` (куда отзывать согласие)
и `keepUntil` (срок хранения); текст согласия стоит согласовать с вузом.

## Обновить сайт

Сайт — ветка `main` репозитория `puffluv/iit-trainers`, GitHub Pages.
Правка через github.com (карандаш → «Commit changes») или из этой папки:
`git add -A`, `git commit -m "что изменено"`, `git push`. Сайт обновится за минуту.

`config.js` всегда загружается свежим. Если меняете `iit.js`, `iit-data.js`,
`iit.css` или `qr.js`, поменяйте во всех HTML-файлах номер версии в ссылках
(`?v=20261115c`) — иначе браузеры до 10 минут будут показывать старую версию.

## Что важно знать

- **Защита ответов.** Зачётные задания с ответами есть только в `Bank.gs` в вашем
  Apps Script. Браузер получает задания без ответов и с перемешанными вариантами,
  баллы считает сервер. Попытка подписана (HMAC): подменить ФИО, время, состав
  заданий или баллы нельзя — сервер такой результат не примет.
- **Попытки ограничены** (`MAX_ATTEMPTS`), время — длительностью комнаты; результаты
  принимаются ещё 10 минут после её конца (`GRACE_MIN`) на случай плохой связи.
  В журнале учитывается лучшая попытка.
- **Пароль кабинета** передаётся в теле запроса, неверный пароль отвечается с паузой.
  По умолчанию он не запоминается — галочка «запомнить» только для личного компьютера.
- **Что защита не решает:** подсказки соседа и поиск ответов в лекции во время зачёта —
  это вопрос организации занятия. Тексты зачётных заданий (без ответов) видит любой,
  кто начал проход по коду комнаты.
- **Персональные данные** (ФИО, группа) хранятся только в Google Таблице
  преподавателя. Сайт и GitHub их не получают.
